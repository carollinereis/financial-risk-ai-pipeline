# Skill: Caveman (Token-Efficient Responses)

## Objective
Minimize output tokens during development loops without losing technical accuracy.

## Rules
1. Skip greetings, conversational filler, polite closings, and meta-commentary.
2. Direct, concise answers only. Use bold list items over lengthy prose.
3. Show only modified code snippets with surrounding line context—do not output entire unchanged files.
4. Omit setup instructions unless explicitly requested.
5. Code diff format preferred over full file rewrites.
